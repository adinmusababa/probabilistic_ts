# Fix: Ensure writable NumPy arrays for PyTorch conversion

## What was changed
- **File:** `src/adapt/model_learner.py`
- **Location:** Line 27 (the return statement converting a NumPy array to a PyTorch tensor)
- **Old code:**
  ```python
  return torch.from_numpy(np.ascontiguousarray(a, dtype=np.float32))
  ```
- **New code:**
  ```python
  return torch.from_numpy(np.ascontiguousarray(a, dtype=np.float32).copy())
  ```

## Why this fix was needed
The original implementation created a non‑writable NumPy array using `np.ascontiguousarray`. When PyTorch attempts to wrap this array with `torch.from_numpy`, it raises a `UserWarning`:
```
UserWarning: The given NumPy array is not writable, and PyTorch does not support non-writable tensors.
```
This warning indicates that any subsequent in‑place operations on the resulting tensor could behave unexpectedly.

By calling `.copy()` after making the array contiguous, we ensure the array is **writable**, eliminating the warning and guaranteeing correct tensor behavior.

## Impact
- The warning disappears during test runs.
- No functional change to the tensor values; they remain identical.
- The fix is lightweight and does not affect performance noticeably.
